# Dice Game

A simple **two-player dice game** built using HTML, CSS, and JavaScript. Each time the page is refreshed, the dice generate random numbers and the player with the higher number wins.

## Features

* Two-player dice game
* Random dice numbers on every refresh
* Automatically determines the winner
* Simple and interactive interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Refresh the page to generate new dice values and determine the winner.

## Purpose

This project was created to practice **JavaScript randomization, DOM manipulation, functions, and basic game logic**.
